## 一、 全球物流枢纽布局与仓网拓扑

集团在全球构建了“三级仓储网络体系”，实现“全球 72 小时达，区域枢纽 24 小时配”：
1. **中心中心仓 (Central Hub)**：
   - **华东总仓（宁波舟山综合保税区）**：库容 35 万立方米，负责亚太及北美核心备货。
   - **华南总仓（深圳前海保税港区）**：库容 28 万立方米，负责消费电子、锂电池专线及东南亚快运。
2. **区域海外枢纽仓 (Regional Overseas Fulfillment Centers, OFC)**：
   - **美西一号仓（美国洛杉矶 Ontario）**：覆盖美西美中 12 个州，日均吞吐能力 15 万单。
   - **欧洲中央仓（德国法兰克福 GVZ）**：覆盖欧盟 27 国，保税转关时效 $\le 18$ 小时。
   - **东南亚枢纽仓（马来西亚吉隆坡 KLIA）**：辐射新加坡、印尼、泰国、越南。

## 二、 危险品（含锂电池）航空运输准入规范

跨境电商电子消费品（如智能手表、无线耳机、无人机、移动电源）普遍内置锂电池，其国际空运及入库存储必须严格遵循国际民航组织（ICAO）《危险品安全航空运输技术细则》及 IATA DGR 第 67 版新规：

### 2.1 锂电池准入分类与 UN 编号
所有含锂电池商品入库前，供应商必须在系统上传由 CNAS / ILAC-MRA 认可第三方实验室出具的 **UN38.3 试验合格鉴定报告**以及 **MSDS（化学品安全说明书）**。

| 类别编号 | 货物类型描述 | 国际 UN 编号 | 单件最大额定能量/净重限制 | 包装与运输强制要求 |
| :--- | :--- | :--- | :--- | :--- |
| **Section IA** | 锂金属电池/电芯单独运输 | **UN 3090** | 锂含量 $> 2\text{g}$（禁止客机，仅限货机） | 必须使用 II 类危险品包装钢桶，贴 Class 9 标签 |
| **Section IB** | 锂离子电池单独运输（如充电宝） | **UN 3480** | 额定能量 $> 100\text{Wh}$ 或净重 $> 10\text{kg}$ | 荷电状态（SoC）出厂严禁超过 **30%**；仅限全货机 |
| **Section II** | 锂电池安装在设备中（如笔记本） | **UN 3481** | 单电池 $\le 100\text{Wh}$，整箱净重 $\le 5\text{kg}$ | 必须防止在运输途中设备意外激活启动；双层绝缘包装 |
| **Section II** | 锂电池与设备放置在同一包装中 | **UN 3481** | 设备内电芯数 $\le 4$ 颗，且单箱总重 $\le 5\text{kg}$ | 需承受 1.2 米跌落试验无破损、无漏液 |

> **关键操作红线**：
> 凡涉及 UN 3480（充电宝等独立锂电池），各保税仓必须设置**独立防爆防静电隔间（Class-9 Hazmat Zone）**，仓内自动灭火系统必须配置**七氟丙烷（HFC-227ea）或细水雾系统**，严禁使用常规干粉或高压直流水枪。

## 三、 温湿度敏感货物（医药冷链与美妆）冷库温控监控标准

保税仓内针对特殊温度敏感货物划分为三级独立温控区，由物联网（IoT）传感器每隔 **60 秒**采集一次温湿度并上报区块链存证：

```
┌────────────────────────────────────────────────────────────────────────┐
│                        温控仓储分区与偏离阈值规约                      │
├────────────────────┬─────────────────────┬─────────────────────────────┤
│ 区域类型           │ 标称目标温度范围    │ 湿度控制范围 (RH)           │
├────────────────────┼─────────────────────┼─────────────────────────────┤
│ 1. 超低温冷冻库     │ -20°C ± 2.0°C       │ 不限 (配置除湿防霜风机)     │
│ 2. 医药恒温冷藏库   │ +2.0°C 至 +8.0°C    │ 35% 至 65% RH               │
│ 3. 恒温阴凉化妆品库 │ +15.0°C 至 +22.0°C  │ 45% 至 60% RH               │
└────────────────────┴─────────────────────┴─────────────────────────────┘
```

### 温湿度偏离应急响应机制（Temperature Excursion）
- 若恒温冷藏库温度连续超出允许区间（超过 8.0°C 或低于 2.0°C）达到 **15 分钟**，系统自动触发短信/电话呼叫仓储值班主管。
- 若超温持续时间达到 **45 分钟**，该批次货品在 WMS 系统中自动被置为 `LOCKED_QC_HOLD` 状态，禁止出库发货，必须由专职医药质检员依据热稳定性数据评估是否做整批报废处置。

## 四、 国际海运滞港费（Demurrage）与滞箱费（Detention）阶梯计费模型

海运集装箱到达目的港码头后，各船运公司提供一定的免费使用期（Free Time），超出期限将按自然日递增收取惩罚性滞纳金：

### 4.1 40英尺高柜（40HQ）标准计费梯阶表（以美西洛杉矶港 LAX 为例）
- **免费期 (Free Time)**：
  - 码头堆存免费期（Port Demurrage Free Time）：**4 个自然日**（自集装箱卸船落堆当日 00:00 起算）。
  - 集装箱用箱免费期（Equipment Detention Free Time）：**7 个自然日**（自提箱离开码头道口起算）。

- **超期阶梯费率（按单个集装箱/自然日累计收取，单位：美元 USD）**：

| 超期天数区间 (Calendar Days) | 码头滞港堆存费 (Demurrage) | 集装箱滞箱费 (Detention) |
| :--- | :--- | :--- |
| **第 1 天 ~ 第 4 天 (Free Time)** | **$0.00** (免费期内) | **$0.00** (免费期内) |
| **第 5 天 ~ 第 9 天 (超期阶段 1)** | **$120.00 / 箱 / 天** | **$95.00 / 箱 / 天** |
| **第 10 天 ~ 第 14 天 (超期阶段 2)**| **$240.00 / 箱 / 天** | **$180.00 / 箱 / 天** |
| **第 15 天及以后 (严重超期恶劣阶段)**| **$450.00 / 箱 / 天** | **$320.00 / 箱 / 天** |

> **调度避坑规则**：
> 当海关查验（Customs Hold）发生时，即使货物非企业过错被扣留，船公司滞箱费依然按日顺延累加。物流调度算法必须在集装箱到港前 48 小时预先完成 EDI 报关单自动核注，杜绝单据缺失滞留。

## 五、 逆向物流与售后退换货（RMA）定损分级标准

全球消费者退回保税仓/退货处理中心的商品，必须由自动化质检设备及专员在 **24 小时**内完成开箱检验，并根据定损结果录入对应的处置流程：

| RMA 判定级别 | 外观与功能状态说明 | 系统处置流向 | 残值回收比例 (相对于出厂成本) |
| :--- | :--- | :--- | :--- |
| **Level A (全新未拆)** | 封签完好无破损，原厂薄膜未撕，支持二次销售 | 重新贴防伪标，即刻回流主库存上架 | **100%** 原值入账 |
| **Level B (开箱轻微)** | 原包装轻微变形，配件齐全，通电开机正常，机身无划痕 | 移送“官翻/清仓专区”，降价 15%~25% 销售 | 估值约为原值的 **75%~85%** |
| **Level C (功能受损)** | 机身有可见划痕，或局部功能偶发失效（如按键卡顿） | 批量整箱打包退回国内原厂保修保税返修通道 | 估值约为原值的 **40%~50%** |
| **Level D (核心故障)** | 主板烧毁、屏幕碎裂、锂电池膨胀漏液或严重进水 | 移送绿色环保资质机构进行物理粉碎与贵金属拆解 | 报废计提损失，残值 **$\le 5\%$** |
