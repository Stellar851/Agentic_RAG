# RAG 权威开源基准数据集与极限压测文档套件说明

## 一、 文件清单与结构
本目录收录了工业界权威的 RAG 测试集规范，包含长文档、密集表格、多层级规范、代码以及短篇 FAQ，同时配备了自带 Ground Truth 的黄金问答对：

1. **`01_超长金融财报_上市公司年度财务业绩与合并报表.md`**：超长文档，包含 4 列以上的合并利润表与资产负债表，重点测试表格切片完备性与跨行多跳计算。
2. **`02_国家技术标准_网络安全等级保护与合规审计规范_GBT22239.md`**：多层级编号技术标准（GB/T），重点测试父子层级元数据继承与多实体联合抽取。
3. **`03_电商售后履约与争议处理规则_含密集排他条款.md`**：密集排他性与例外商品规则，重点测试 0.40 硬截断、例外否定句识别与诚实拒答。
4. **`04_开发者API与系统架构技术手册_含代码块与配置.md`**：包含完整 FastAPI Python 异步代码块与 Redis YAML 配置，重点测试 BM25 稀疏精确匹配。
5. **`05_短篇FAQ业务问答与单点规则库_20条.md`**：20 条短文本高频问答，测试短句检索与抗稀释能力。
6. **`01_FinanceBench_金融长文档与表格专家评测集_带标注.json`**：对标 FinanceBench 金融评测集的专家问答对。
7. **`02_RGB_中文长文档抗噪与反事实黄金评测集.json`**：对标人民大学 RGB 基准集，包含负向拒答诱导样本。
8. **`03_Ragas全流程量化评测统一测试集_可直接跑评测.json`**：标准 Ragas 四维评测格式（question / ground_truth / contexts），可直接送入 evaluation_center 运行。
